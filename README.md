# AKRASC 3.0 Website

Official website for **AKRASC (All Kerala Robotics and Automation Student Conclave 3.0)** under the **IEEE Robotics and Automation Society (RAS) Kerala Chapter**.

This website serves as a platform to showcase the initiatives, events, achievements, and activities organized by the RAS Kerala Chapter and the AKRASC community.

---

## Live Website

https://akrasc.ras.ieeekerala.org

---

## About the Project

The AKRASC website provides a centralized platform for:

* Highlighting IEEE RAS Kerala Chapter initiatives
* Showcasing AKRASC events and community activities
* Sharing achievements and updates
* Promoting robotics and automation initiatives in Kerala
* Providing information about student engagement programs

The project is built as a **static website** and hosted using **cPanel-based web hosting**.

---

## 🛠 Tech Stack

The website is built using the following technologies:

* **HTML5**
* **CSS3**
* **JavaScript**
* Static assets (images, icons, media)

No backend framework is used; the site is deployed as a **static website**.

## 🚀 Deployment

The website is currently hosted on:

```
akrasc.ras.ieeekerala.org
```

Deployment is done through **cPanel File Manager** by uploading the updated project files to the server directory.

Typical deployment workflow:

1. Update the website locally.
2. Push changes to GitHub.
3. Upload the latest files to the server.
4. Verify the live deployment.
